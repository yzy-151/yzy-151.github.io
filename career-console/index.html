自我介绍 · 通信版（更新版）
面试官你好，我叫袁振洋，本科和硕士都毕业于哈尔滨工业大学深圳校区，我的专业是电子信息，研究方向是通信的物理层算法，具体的课题是射频前端的一种叫无源互调的干扰抑制。我在华为已经实习了一年，主要分为三块内容。第一是关于射频前端一种叫无源互调的干扰的抑制，通过轻量化的神经网络建模这个互调干扰，再在接收端减去他。我主要负部分责线性层网络的设计与实验设计和实验验证，通过扩展模型层数实现了对辐射场景的无源互调建模的2dB性能提升。第二部分是针对轻量化网络的收敛加速问题，调研并仿真了一些前沿的优化器，落地了Eadam优化器，通过引入历史梯度差，在收敛速度上实现了最大1.45倍的加速效果，并解决了后期收敛振荡问题。第三块是我的课题，也是关于无源互调的抑制，我们通过导频获取无源互调的空间信息，通过波束搜索得到一个近似SVD分解的特征空间和对应的特征值，然后逐特征值去迫零干扰，最后得到一个能避开干扰源的波束赋形投影矩阵，主要应对辐射类型的无源互调。以上就是我的实习经历也是我自我介绍的主要内容
自我介绍 · Agent版
我的项目重点是 Agent 工程。先在 Nonlinear NN Agent 从零实现 Planner、Tool Registry、Hook、Session、Trace、Reflection 和 SSE；之后用 LangGraph 和 STORM 构建 PaperStorm，完成 Hybrid RAG、可恢复 Context、跨会话 Memory、企业 ACL 和 Benchmark。既理解 Harness 内核，也能用成熟框架落地。
难点案例 STAR（基带验证）
验证辐射 PIM 特征值 1~6 场景数据无法闭环，有 DDL。我及时上报，把复杂环境降为简单环境逐步排查，确认是多芯片采集不同步，联系开发重写采数软件解决。结果：1~6 特征值全部验证通过。收获：异常先降复杂度定位，再借团队视角。

华为联培项目重心在工程落地。PIM 对消和 Eadam 属内部预研，方向敏感不方便发论文，但有实打实工程验证。毕设（波束赋形抑制 PIM）已到会议撰写阶段，年底前投出。

基于轻量化 CNN 的 FDD MIMO 互调干扰建模对消（华为实习）
2025.07–2026.03
• 项目背景：射频系统的接收机受到非线性的互调干扰。在接收端建立 CNN 模型拟合并对消该干扰 • 核心贡献：负责轻量化 CNN 模型的结构设计、超参数仿真与实验验证，面向 FDD MIMO 接收链路互调干扰，将群时延、非线性激发和空间耦合等物理过程用神经网络的全连接、分组卷积与非线性层组合建模。模型由 5 层扩展为 7 层（全连接-卷积-全连接-非线性-全连接-卷积-全连接），新增两端全连接层建模天线通道间的泄露 • 核心贡献：参与设计非线性函数改进，以分段线性插值函数替换幂级数非线性函数，解决传统多项式在边缘输入区拟合精度不高的问题 • 项目成果：以神经网络建模信号传输的物理过程，建模对消能力平均提升 2 dB，在有泄露场景中额外提升 1.5 dB
基于历史梯度差分的轻量化抗干扰模型收敛加速
2025.11–2026.07
• 项目背景：面向通信系统中的神经网络拟合任务，为满足通信的实时性，通过改进优化器实现网络收敛加速 • 核心贡献：独立调研和仿真 Muon、CAdam、Eadam 等优化器，Eadam 在 Adam 基础上，增加历史梯度差累积项近似 Hessian 矩阵，在梯度较大时，梯度累积量进一步加速，在小 batch 下实现对 AdamW 1.45 倍收敛加速 • 核心贡献：针对 Eadam 后期梯度减弱导致的历史梯度差噪声增大、收敛曲线振荡问题，独立设计 alpha 参数随梯度大小自适应衰减策略，在保持 1.45 倍加速效果的同时消除振荡，实现了 Eadam 优化器应用的二次改进 • 项目成果：相对 Adam 算法实现 1.45 倍加速效果，算法已通过预研进入 FPGA 在板验证阶段
基于多天线波束赋形的 MIMO 无源互调干扰抑制（毕业设计）
2025.09–2026.12
• 项目背景：针对射频链路中的互调干扰，在发射端通过波束赋形抑制干扰激发，与接收端建模对消同时工作 • 核心贡献：从相关性角度建模干扰，通过信号矩阵协方差的 SVD 分解得到的（特征向量-特征值）表征（独立干扰-干扰能量大小），通过有限差分法搜索干扰的特征向量，设计迫零干扰权值矩阵的波束赋形权值实现干扰抑制 • 核心贡献：通过权衡用户发射功率与迫零力度，设计用户通信质量阈值作为波束赋形约束，实现全通道用户功率回退不超过 1.5dB • 项目成果：微波暗室实际采集多组数据，验证不同数量源以及不同量级干扰，证明其对外部干扰源产生的干扰具有优良抑制效果，实测阵列级抑制效果达 10dB，已进入会议撰写阶段
